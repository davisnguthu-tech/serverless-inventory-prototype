💡 System Architecture Flow

Decoupled serverless architecture reading stock catalog from Redis cache populated by periodic sync.

Layer 1
Warehouse API
Single source of truth stock catalog (/api/warehouse/inventory)
Layer 2
Scheduled / Manual Sync
Vercel Cron (5-min schedule) or manual trigger (/api/sync-inventory)
Layer 3
Redis Cache
High-speed key-value cache storing product records & metadata
Layer 4
Inventory Query API
Fast serverless endpoint (/api/inventory) reading directly from Redis
