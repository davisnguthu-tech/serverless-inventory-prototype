💡 How It Works

This web interface communicates directly with stateless Node.js serverless functions running on-demand.

Step 1
HTTP Request
Client triggers a GET request via fetch() to the serverless route.
Step 2
Function Execution
Vercel spins up the endpoint handler on demand to process logic.
Step 3
JSON Response
Returns structured JSON payload and HTTP status code before going idle.
